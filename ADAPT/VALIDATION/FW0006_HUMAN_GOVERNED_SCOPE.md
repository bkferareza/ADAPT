HUMAN_GOVERNED is the sole recovery model. HUMAN_SUPERVISED remains a compatible
existing API label for that model. Autonomous privileged recovery is removed,
including optional, configured and future execution modes. No independent process,
protected account, OS-specific identity verifier, TrustedHost, GitHub trust chain,
external policy/approval server, authentication deployment or operator ceremony is
required. No authentication subsystem, dispatcher or generic fixer is added.

Assurance reduction is explicit: conversational approval is not independently
authenticated, cryptographically proven or tamper-proof. This design does not
protect against a hostile agent with unrestricted filesystem/approval-record
access. Identity and access to normal interaction belong to the organization.
