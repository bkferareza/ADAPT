# COMMAND_REGISTRY.md
STATUS: DRAFT

## Purpose
This registry defines every supported ADAPT command: its authority requirements, inputs, outputs, routing target, and approval gates. An AI agent must validate any incoming command against this registry before acting. Any command not listed here is NOT a valid ADAPT command and must be rejected and reported to the Director.

## Optional read-only operator interface

`TOOLS/adapt.py` offers state, doctor, prompt next and evidence. These inspect or
prepare previews of existing records; they are not additional executing ADAPT
commands. See TOOLING_DECISION_CONTRACT.md for explicit binding selection. No
CLI result bypasses approval gates or authorizes execution.

## Notes

1. **{{DOUBLE_BRACE}} placeholders** in command names (e.g., `{{DOCUMENT}}`, `{{MILESTONE_ID}}`, `{{IDENTITY}}`, `{{ROLE}}`, `{{WORKCELL_ID}}`, `{{GAP_ID}}`, `{{BLK_ID}}`, `{{ITEM}}`) must be replaced with actual values when issuing the command.
2. **Mutation Allowed = NO** means the command produces ADAPT artifacts (registers, logs, plans, reports, handoffs) but does not write or modify application source code.
3. **Approval Required = YES** means an AI agent must halt and request human confirmation before proceeding. Proceeding without approval is a GOVERNANCE_VIOLATION.
4. **Stop Conditions** are evaluated before execution. If any stop condition is true, the agent must stop, record the stop reason, and route to the Director.
