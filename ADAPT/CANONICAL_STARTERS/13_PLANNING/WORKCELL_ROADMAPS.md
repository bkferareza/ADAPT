## Purpose

This file records roadmap recommendations per workcell for the current milestone. Roadmaps are proposed by the Planning Lane and must be submitted to the Director for approval before workcells are directed to follow them. Only Director-approved roadmaps are recorded here.

## Notes

- Sequence indicates the recommended execution order within the workcell for this milestone.
- Dependencies reference SEQ-ID entries in DEPENDENCY_SEQUENCES.md.
- Status reflects the current state of the business item within the workcell roadmap.

## Status Values

- PLANNED — scheduled but not yet started
- IN_PROGRESS — workcell is actively working this item
- BLOCKED — execution is blocked; see BLOCKER_REGISTER.md
- COMPLETE — item completed and accepted
- DEFERRED — moved to a later milestone by Director decision
