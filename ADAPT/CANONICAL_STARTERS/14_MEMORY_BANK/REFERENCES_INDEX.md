## Purpose

This index records reference materials stored in the Memory Bank. The Memory Bank holds non-authoritative reference content only — research artifacts, architecture notes, prior decisions that have since been superseded, external references, and lessons learned. This content informs but does not govern.

## IMPORTANT — Reference Only

Memory Bank is REFERENCE ONLY. Content here is not live source authority.

- For authoritative decisions, see DECISION_LOG.md in `02_DIRECTOR_LANE/`.
- For source truth, see documents in `01_SOURCE_TRUTH/`.
- For active contracts, see `04_INTEGRATION/`.

Do not cite Memory Bank content as the basis for ADAPT decisions. If a Memory Bank item warrants promotion to source authority, route it to the Director for a formal decision.

## Type Values

- Architecture Note — non-binding architecture observation or sketch
- Research Artifact — findings from research, spikes, or exploratory work
- Prior Decision (non-binding) — a decision from a prior phase or project that is informative but does not bind this project
- External Reference — external documentation, standards, or specifications
- Lesson Learned — post-action observation about what worked or did not work
