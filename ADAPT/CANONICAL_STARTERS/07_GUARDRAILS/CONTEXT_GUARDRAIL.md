# CONTEXT_GUARDRAIL

STATUS: DRAFT
PROJECT: {{PROJECT_NAME}}
GUARDRAIL_ID: {{GUARDRAIL_ID_CONTEXT}}

## Enforcement Rule

Execution must not proceed with stale, superseded, or untraced context.

## Trigger Conditions

- The active context pack does not reference a specific source truth version identifier from 01_SOURCE_TRUTH/SOURCE_TRUTH_VERSION_LOG.md
- One or more artifacts in the context pack are tagged to a superseded source truth version (i.e., a version that has been replaced by a newer entry in SOURCE_TRUTH_VERSION_LOG.md)
- A context pack is missing entirely for a non-trivial action (any action that mutates files, closes a business item, or produces a deliverable artifact)
- The declared context budget for the action exceeds the declared context window size for the model or role operating the workcell
- The context pack references documents that have been updated since the pack was built, and the pack has not been rebuilt to reflect those updates

## Outcome Types

### PASS

The context pack is present, references a current source truth version, all artifacts are from the current version, and the context budget is within declared limits. Proceed with execution.

### WARN

The context pack is partially complete or is approaching staleness (e.g., one artifact is from the prior source truth version but the relevant section has not changed). The AI agent must declare all known limitations explicitly in its output and in the next handoff artifact. Proceed with documented limitations only.

### STOP_REQUIRED

The context pack is stale (references a superseded source truth version), untraced (no source truth version reference), or missing for a non-trivial action. The AI agent must stop immediately, record GAP-T11 in 02_DIRECTOR_LANE/GAP_REGISTER.md, and request the Context Steward to rebuild the context pack before any execution resumes. Do not produce deliverable artifacts under stale or untraced context.

## AI Behavior When Fired

| Outcome | AI Must | Record In | Route To |
|---------|---------|-----------|----------|
| PASS | Proceed with bounded action | — | — |
| WARN | Proceed with declared limitations; document all known gaps | Active work log; next handoff artifact in 06_HANDOFFS/ACTIVE/ | Director (informational) |
| STOP_REQUIRED | STOP. Do not execute the action. Record GAP-T11. Request context pack rebuild. | 02_DIRECTOR_LANE/GAP_REGISTER.md (entry: GAP-T11); 06_HANDOFFS/ACTIVE/ | Context Steward; Director lane |

## Override Requirements

There is no override for this guardrail. Stale or untraced context is never acceptable for execution. A new context pack must be generated by the Context Steward before any execution can resume. A Director may not authorize execution under stale context — the enforcement is absolute.
