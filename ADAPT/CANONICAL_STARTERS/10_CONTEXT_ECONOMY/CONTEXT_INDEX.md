## Purpose

This index records all context packs produced within this ADAPT instance. The Context Steward updates this index each time a context pack is assembled or its status changes.

## Status Values

- ACTIVE — context pack is current and valid for use
- STALE — context pack references superseded source truth or outdated artifacts; must not be used
- SUPERSEDED — source truth version has been promoted; this pack is no longer valid
- ARCHIVED — context pack is retired and stored for audit reference only
